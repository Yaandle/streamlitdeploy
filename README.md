# StreamlitDeploy

**Purpose:** Demonstrates deployment of YOLOv8 computer vision models for detection and segmentation tasks in a Streamlit web interface.

---

## Overview

This app allows testing and demonstration of **YOLOv8 models** on single images, multiple images, or video sources. Users can:

- Select a pre-trained model or upload a custom YOLOv8 model
- Choose a task: **Detection** (bounding boxes) or **Segmentation** (masks)
- Process **single images**, **multi-image batches**, or **video files**
- Download processed results for further use

This repo is part of a **deployment literacy showcase** and was originally part of the ODIS project family.

---

## Features

### Multi-Feature Inference Testing

1. Select a model (or upload your own)
2. Select a task (Detection / Segmentation)
3. Upload a single image, multiple images, or a video
4. Process and download the results
